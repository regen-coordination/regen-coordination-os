# 2026-07-29 — Discourse hub migrated to self-hosting

**Focus:** Scope and execute the full migration of `hub.regencoordination.xyz` off Discourse managed hosting onto self-hosted infrastructure. Completed end-to-end in this session.

## Outcome

**Live on self-hosted infrastructure since 2026-07-29.** Same domain, same logins, same content, zero data loss.

- **Cost: ~$100/mo → ~$8.40/mo** (Hetzner cx23 €6.49 + snapshots €1.30; Brevo email free tier) — **~$1,100/yr saved**
- 188 users · 160 topics · 938 posts · 154 MB uploads, all verified intact
- Verified by operator: password login, **Discord login**, images, posting, admin access
- Email fully authenticated: SPF/DKIM/DMARC all PASS, DKIM aligned to `regencoordination.xyz`

## Key decisions

1. **Hetzner over Railway/Hostinger/Fly.** Driver was cost. Discourse only officially supports Docker-on-a-VM, so PaaS was rejected as unsupported *and* more expensive. Hetzner also exposes a full API, enabling agent-driven provisioning.
2. **cx23 (2 vCPU / 4 GB / 40 GB, €6.49/mo)** — plan originally said cx32, which Hetzner retired in a CX renumbering; the successor cx33 had **no capacity in any datacenter worldwide**. cx23 meets Discourse's *recommended* production spec (4 GB) and came in cheaper than planned, with a 2 GB swap file for rebuild headroom.
3. **Cancellation-triggered backup.** The self-serve backup is DB-only — uploads live on Discourse's CDN. Support confirmed the full backup *with uploads* is produced by the **cancellation process**. Cancelling set a hard decommission date of 2026-07-30, which drove the timeline.
4. **Disabled** `discourse-ai` features and reply-by-email (no inbound mail on self-host); **kept** Discord login (credentials came across in the DB restore — no need to re-fetch the secret).

## Hard-won lessons (documented in the runbook)

- **Google/Yahoo 2024 sender rules make DMARC mandatory.** Missing DMARC + SPF not authorising Brevo + domain unauthenticated in Brevo = Gmail *silently discards* mail. No bounce, not even a spam copy. This cost the most debugging time; initially judged DMARC and the branded CNAMEs "optional" — they are not.
- **All 14 plugins ship with the Discourse base image.** An explicit `git clone` of `discourse-lazy-videos` *breaks* the bootstrap (`destination path already exists`, exit 128).
- **`force_https` restores as `true`** from hosted, which hangs a staging site served over plain HTTP on the loading spinner (HTML 200, then JS calls https with no TLS listener).
- **`rails runner` must run as the `discourse` user**, not root, or it fails with `ActiveRecord::NoDatabaseError`.
- Restore auto-remaps CDN URLs, but **cooked HTML still needs `rake posts:rebake`** (351 posts were stale until rebaked).
- The macOS shell is zsh: the `SSH="ssh …"; $SSH '…'` pattern silently fails (no word-splitting).
